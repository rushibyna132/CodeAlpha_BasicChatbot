Basic Chatbot

Description

This project is a simple rule-based chatbot created using Python. It interacts with the user through the console and provides predefined responses to common messages.

Features

- Greets the user.
- Responds to common greetings like Hello, Hi, Hey, and Hii.
- Responds to "How are you?"
- Tells the chatbot's name.
- Responds to thank-you messages.
- Supports good morning, afternoon, and evening greetings.
- Ends the conversation when the user says "bye" or "goodbye".
- Gives a friendly response for messages it does not understand.

Technologies Used

- Python
- Google Colab

Concepts Used

- Functions
- While loop
- If-elif-else statements
- User input and output
- String methods

How It Works

The chatbot takes input from the user and checks the message against predefined rules. Based on the input, it displays a suitable response. The conversation continues until the user says "bye" or "goodbye".

Example

🤖 Hello! I'm your chatbot.
You can chat with me, or type 'bye' to exit.

You: Heyy
Bot: Hey! 😊 Nice to meet you!

You: How are you doing?
Bot: I'm doing great! Thanks for asking. How are you?

You: What is your name?
Bot: I'm a simple Python chatbot. You can call me ChatBot!

You: Bye
Bot: Goodbye! 👋 It was nice chatting with you!
